# Literature watch, 2 November 2026

Papers first submitted 24 October to 2 November. 17 candidates from 30 queries; 4 kept. The first run, made the day the watch was set up (`research/LITERATURE-GAPS.md`).

## Kept

- **Accept Changes, Reject Attacks: Robust Memory Management for LLM Agents.** 29 Oct. [arXiv 2610.41056](https://arxiv.org/abs/2610.41056). A memory manager has to accept facts that have changed and reject passages planted in it, two opposite rules for writing. Existing memory systems handled both no better than an untuned manager. Their score, evidence-conditioned accuracy, counts an answer right only if the records chosen hold all the evidence it needs, up to date. *Promising.* **Bears on:** A, T41. **Changes:** nothing. T41's retrieval bar already asks for the complete relevant evidence with nothing superseded; this paper confirms that is the right measure.
- **Finding Is Not Returning, Returning Is Not Reconstructing: Agent Social Re-entry.** 29 Oct. [arXiv 2610.39781](https://arxiv.org/abs/2610.39781). It separates three abilities: finding an earlier conversation, choosing to return to it, and picking it up coherently. Resurfacing helped finding, and persistent memory helped returning; neither helped the pick-up. *Promising.* **Bears on:** A, and his relationships over months. **Changes:** nothing now. *Judgment:* a measure for Act 2: from the day files, count how often he goes back to someone met earlier, and whether he picks up where they left off.
- **ConMem: Counterfactual Probing for LLM Memory Misalignment.** 24 Oct. [arXiv 2610.33432](https://arxiv.org/abs/2610.33432). A benchmark of 1,079 memory cases (MemAlign), with misattributed memories as a named category. *Promising.* **Bears on:** A, G1. **Changes:** G1 could borrow its taxonomy of memory errors for its labels.
- **Auditable Belief Updates as a Missing Safety Layer for LLM-Powered Multi-Agent Systems.** 28 Oct. [arXiv 2610.38869](https://arxiv.org/abs/2610.38869). A position paper. Beliefs are held as explicit state linked to evidence; operators propose changes, and a firewall bounds or rejects weakly evidenced ones. There is no evaluation. **Bears on:** D, T42. **Changes:** nothing. It has the same shape as T42's evidence gate, so it confirms the direction without adding evidence.
