## Trainer

pc/train_hegel.py --round-two --phase restyle uses the separate pc/restyle_round2.py path and new output directory. Defaults are rank 16, alpha 32, learning rate 2e-4, all attention/MLP modules and effective batch 8. Step-based evaluation and saving occur every 100 steps, with a terminal evaluation when needed. Exactly 20 unique full held units, version 1, are fixed before model loading; fewer stop the run. No truncation or silent example dropping is allowed. All checkpoints remain.

Optional --goldfish masks loss labels only: a SHA256 hash of the preceding 13 target token IDs selects approximately one in four subsequent target tokens with k=4. Prompt/padding labels stay ignored; the first 13 target tokens remain supervised and context is never removed. Hashing is deterministic across prompts and epochs. Held-out loss is measured on the full held target.

The declared machine selection policy, for Claude's review, is lexicographic: fewer units with recall beyond input, then lower aggregate Delta, lower held-out loss, then earlier step. It uses no human choices. Every held request/output and its metrics checksum is retained; an incomplete generation stops without resampling. Mocked training verified that the best measured checkpoint, rather than the last checkpoint, is exported. This is CPU wiring evidence; actual GPU compatibility, training time and quality remain unmeasured.

## New test and copying guard

It freezes the first forty actual thoughts of at least forty words from Days 12, 24, 25, 26, 27 in that order, excluding later-person names against Day 1's known cast. One twenty-pair sheet goes to Welt and a disjoint twenty-pair sheet to Claude. Each pair occurs once. Public JSON/HTML contains the thought and A/B options only, with no model roles, source-day labels or answer key. One chosen profile can be exported for the cohort, preventing repeated sheets from consuming the same blind material. The original T29 sheets/keys/judgment are unchanged.

Both arms use the same plain base decisions for the twenty live-contract situations; only thought is restyled, then the actual contract is checked again. Meaning uses fixed plain Qwen, temperature zero and exactly two booleans, with no retry for a favorable answer. Adapter/control/judge routing is explicit per request; the control, base mind and judge remain plain. Aggregate Delta, both-yes meaning count, shelf copying, valid/refused/leaking counts and every restyle's original recorded wall time are reported. The numerical boundaries are 0.38, 36/40, 1/40, 20 valid/no leaks and 8 seconds. A human voice score and Welt's first-ten meaning review remain required; machine-only output always leaves the overall five-KPI result incomplete.

The optional world/restyle.py guard indexes all shelf works and languages once, confirms each hash hit against exact normalized source text, and checks twelve-word runs across passages within a work, never across books. One retry follows a copied, empty or truncated answer; another failure returns the exact plain thought. All attempts and timings remain. It is used by the new benchmark and is available to a later runtime caller; it has not been enabled in the live world. A saved-output reconstruction diagnostic subtracts runs already in the plain input and is explicitly non-gating; it makes no model calls.

Labeled meaning review is blocked until actual exported choices are frozen and a real Git commit contains both files byte-for-byte. This keeps the first-ten review from revealing the adapter before blind preferences are committed. No actual judging choices or score were manufactured by the CPU tests.
