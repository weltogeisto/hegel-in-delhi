# mind/train: the data for Hegel's LoRA

Generated on the PC by `tools/train_data.py`, read by `pc/train_hegel.py`, run by `pc/TRAINING.md`. **Only this README is committed**; every other file in this folder is ignored by git (`.gitignore`). The data is big, it is made from the PC's own run, and it must never be edited by hand.

## The rule

No assistant turn in this data is written by Claude. Anthropic's terms bar training other models on Claude's output, so each target comes from one of two places:

- **Hegel's own texts**, public domain: `corpus.jsonl`, cut from the shelf (`mind/shelf/*.txt.gz`).
- **Qwen itself**: `decisions.jsonl`, `plans.jsonl`, `writings.jsonl`, `voices.jsonl`, the mind's own answers to the world's own prompts.

The one exception is `general.jsonl`, below, which is human-written (or, with `--answer-with`, Qwen-written). Prompts are the project's own files: the soul (`mind/soul.md`), the voices' card (`mind/voices.md`) and the situations that the world engine renders. Nothing here is a thought, an answer or a scene that Claude made up. The tests' fixtures are made-up strings, but they go to temporary folders and never into this one.

## The files

| File | What | Made by | Lines |
|---|---|---|---|
| `corpus.jsonl` | Phase 1, continued pretraining: his books, in documents of at most 6,000 characters under a header line (`Hegel, Grundlinien der Philosophie des Rechts, §188`; an English text adds the translator and year) | `--corpus`, about 10 s, anywhere | `{"text": "..."}` |
| `decisions.jsonl` | Phase 2: the live prompt and the best valid answer of K candidates | `--distill`, on the PC with Qwen | `{"messages": [system = the soul, user = the rendered situation, assistant = the chosen JSON], "meta": {...}}` |
| `plans.jsonl` | the morning plan call that the world accepted | `--distill` | same, the user turn ends with the plan question |
| `writings.jsonl` | what he wrote when he sat down to, that the world accepted | `--distill` | `[system, user, assistant = the decision, user = the writing ask, assistant = the writing]`; only the last answer is trained on |
| `voices.jsonl` | what the people he meets answered (their own prompt, `mind/voices.md`) | `--distill` | `[system = voices.md, user, assistant = {"says", "does"}]` |
| `general.jsonl` | Phase 2 balance, one general example for each of the above, so that the adapter keeps answering other things too | `--general N` | `{"messages": [...], "meta": {...}}` |
| `rehearsal/` | the scratch world of the distillation: its day files are the state that a resume carries on from | `--distill` | not data |

`meta` carries what the tool needs to resume and to be audited: the step key (`2026-10-04T09:30`, or `...|plan`, `...|voice|1`, `...|write`), the day, the number of candidates and how many were valid, the score and its parts, the try (1, or later after the world's refusals). The trainer reads `messages` only.

## The distillation

The world rehearses days with the real Qwen as the mind (the machinery of `python3 -m world simulate`: no git, feeds off). At each decision Qwen is asked K times at temperature 0.9 with the live schema. The world checks every candidate (the rules, the 1831 gate, the repetition guard); the valid ones are scored by a plain heuristic, the best is taken, the day goes on from it. The heuristic is written out in the docstring of `tools/train_data.py`: it likes a thought of 25 to 90 words that uses what happens, who is there, what is for sale or the passage under "From your shelf"; it dislikes stock phrases, copying the soul's example thoughts and opening every thought the same way. An answer the world would refuse is never written. A decision with no valid candidate is refused as it would be live, and Qwen is asked again.

Resumable: every example is appended with its step key; a crash, a Ctrl-C or a PC that stops answering ends the run without losing a step, and the same command carries on, replaying recorded steps without asking again.

Time on the PC: about (K + 3) calls per decision, 20 days of about 26 decisions at K = 4 is 4 to 7 hours.

## The general set

`--general N` reads N examples from [`allenai/tulu-3-sft-mixture`](https://huggingface.co/datasets/allenai/tulu-3-sft-mixture) (Ai2, ODC-BY-1.0) through the Hugging Face datasets-server rows API, stdlib only.

- **Source:** only the two subsets that people wrote, `oasst1_converted` (OpenAssistant, Apache-2.0, volunteers) and `tulu_v3.9_aya_100k` (Aya, Apache-2.0, annotators). The mixture's other sets were generated by language models (GPT-4, GPT-4o and others, among them the Tulu personas sets), or are non-commercial (No Robots), or are one-word task labels (FLAN), and are left out. This is done so that no Claude-generated text can come in through a third party.
- **License:** ODC-BY-1.0 for the mixture, Apache-2.0 for the two subsets; every line says so in its `meta`. Attribution: Ai2, the Tulu 3 SFT mixture (Lambert et al., 2024); OpenAssistant (Köpf et al., 2023); Aya Dataset (Singh et al., 2024).
- **Filter:** English (a stopword test on the text), one to three exchanges, no system turn, at most 3,000 characters, an answer of at least 40 characters.
- **Caveat:** "human-written" is what the dataset cards say. Volunteers may have pasted a model's answer into OpenAssistant, and that cannot be ruled out. If the rule is to be kept to the letter, `--general N --answer-with http://127.0.0.1:8080` keeps the questions and lets Qwen write the answers (one more call each, about 10 s per example).

## Regenerating

```bash
python3 tools/train_data.py --corpus
python3 tools/train_data.py --general 1000
python3 tools/train_data.py --distill --url http://127.0.0.1:8080 --days 20 --candidates 4 --start 2026-10-03
python3 tools/train_data.py --stats                  # counts, token estimates (characters / 4), random samples to read
python3 pc/train_hegel.py --check-data               # validates the files; needs no GPU
```

`--serve-stub 8099` starts a stand-in llama-server so that `--distill` can be tried without the PC. Its answers carry the marks `(rehearsal)` and `(stub)`; `--distill` writes them to a temporary folder, never here, and both `--stats` and `--check-data` refuse any file that contains such a mark.
